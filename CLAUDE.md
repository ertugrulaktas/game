# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is an early-stage game development project. The repository currently contains only a README; no build system, language, engine, or framework has been established yet.

When contributing as the first code is added, agree with the user on the technology stack (e.g. language, engine, package manager) and update this file with the actual build/test/lint commands before writing further code.

## Conventions to Establish

Once a stack is chosen, document the following here:

- **Build command** – how to compile or bundle the game
- **Run command** – how to start a local development session / game server
- **Test command** – how to run the full test suite and a single test in isolation
- **Lint/format command** – the linter and formatter in use
- **Architecture overview** – game loop, scene/state management, asset pipeline, and networking (if any)
