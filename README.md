# Yılan Oyunu

Tarayıcıda çalışan, saf HTML/CSS/JavaScript ile geliştirilmiş basit bir yılan oyunu.

## Özellikler
- Yön tuşları ve `WASD` kontrol desteği
- Skor ve `localStorage` ile en yüksek skor kaydı
- Elma yedikçe artan hız
- Yeniden başlat butonu

## Çalıştırma
Dosyaları bir klasörde tutup `index.html` dosyasını tarayıcıda açmanız yeterli.

İsterseniz yerel sunucu ile de çalıştırabilirsiniz:

```bash
python3 -m http.server 8080
```

Ardından `http://localhost:8080` adresine gidin.
